# Selecția curentă de surse

## Stare

- Sarcină: realizarea catalogului și a instrucțiunilor de selecție.
- Dependențe de aplicație: niciuna; acest folder conține documentație.
- Repository-uri descărcate: **0**.
- Motiv: pentru această sarcină au fost suficiente sursele oficiale consultate online.
- Ultima verificare: 1 octombrie 2026.

## Fișă pentru următoarea selecție

Completează fișa numai când apare o sarcină concretă. Înregistrează separat fiecare repository; nu copia automat toate intrările din catalog.

| Câmp | De completat |
| --- | --- |
| Sarcină și criteriu de acceptare | Rezultatul concret și verificarea lui |
| Stack existent | Din manifest, lockfile și configurația proiectului |
| Biblioteca necesară | Pachetul/runtime-ul efectiv folosit |
| Întrebare nerezolvată | Ce trebuie aflat din sursă |
| Documentație consultată | Link și versiune |
| Repository oficial | URL fără credențiale |
| Versiune instalată | Versiunea exactă, nu un interval |
| Tag și commit | Tag verificat și SHA complet după descărcare |
| Cale locală și metodă | `references/<name>` sau `repos/<name>` |
| Licență | Fișierul și identificatorul la commit-ul ales |
| Fișiere utile | Exemple, teste, API și implementare relevante |
| Rezultat | Întrebarea rezolvată și ce s-a verificat în aplicație |
| Stare | Activă sau inactivă; fără ștergere automată |
