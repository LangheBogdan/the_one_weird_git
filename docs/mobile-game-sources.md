# Surse pentru aplicații, jocuri și desktop

Verificat la 1 octombrie 2026 în documentația și repository-urile oficiale. Catalogul are **12 opțiuni**, dintre care se aleg numai cele folosite de proiect. „Când merită sursa local” reprezintă recomandarea acestui ghid: un checkout pentru cercetarea implementării, separat de instalarea pachetului/SDK-ului necesar aplicației.

| Tehnologie și surse oficiale | Tip, platforme și utilizare potrivită | Când merită sursa local |
| --- | --- | --- |
| **React Native** — [repository](https://github.com/react/react-native), [docs](https://reactnative.dev/docs/getting-started) | Framework pentru aplicații cu UI nativ Android/iOS, folosind React. Potrivit pentru ecrane, formulare și integrare cu dispozitivul; nu este game engine. | Investighezi comportamentul componentelor native, un crash în framework sau integrarea unui modul nativ. |
| **Expo** — [repository](https://github.com/expo/expo), [docs](https://docs.expo.dev/) | Framework și instrumente peste React Native, pentru Android, iOS și web; potrivit pentru o aplicație React Native cu routing și module pentru dispozitiv. | Problema concretă ține de un modul Expo, Expo Router, config plugins sau procesul de generare nativă. Citește întâi pachetul relevant din monorepo. |
| **Flutter** — [repository](https://github.com/flutter/flutter), [docs](https://docs.flutter.dev/) | Framework de aplicații în Dart pentru mobile, web și desktop, cu propriul sistem de widgets. Potrivit pentru interfețe multiplatformă. | API-ul unui widget ori comportamentul de layout/rendering rămâne neclar după docs; inspectează întâi sursele deja prezente în SDK. |
| **Capacitor** — [repository](https://github.com/ionic-team/capacitor), [docs](https://capacitorjs.com/docs) | Runtime nativ pentru aplicații web, cu acces la API-urile dispozitivului prin plugins. Potrivit pentru a distribui un frontend web existent pe Android/iOS. | Investighezi granița web/native, lifecycle sau un plugin. Pentru o problemă de plugin, alege repository-ul pluginului, dacă este separat. |
| **Godot** — [repository](https://github.com/godotengine/godot), [docs](https://docs.godotengine.org/en/stable/) | Game engine cu editor pentru jocuri 2D/3D; export pentru desktop, mobile și web, cu restricții în funcție de limbaj și platformă. | Suspectezi un bug în engine, ai nevoie de o modificare în engine sau de un build personalizat; pentru primul joc pornește cu editorul și docs. |
| **Phaser** — [repository](https://github.com/phaserjs/phaser), [docs](https://docs.phaser.io/phaser/getting-started/what-is-phaser) | Game framework 2D pentru browser, inclusiv browser mobil; include scene, input, animații și physics. Distribuția ca aplicație mobilă necesită un wrapper. | Ai nevoie de comportamentul exact al scenelor, physics, input sau lifecycle pe versiunea folosită. |
| **PixiJS** — [repository](https://github.com/pixijs/pixijs), [docs](https://pixijs.com/8.x/guides/getting-started/intro) | Renderer 2D pentru web; potrivit pentru animații și conținut interactiv. Logica jocului și sistemele suplimentare se construiesc separat. | Investighezi rendering, filtre, texturi sau performanță într-un proiect care chiar folosește PixiJS. |
| **Three.js** — [repository](https://github.com/mrdoob/three.js), [docs](https://threejs.org/docs/) | Bibliotecă 3D pentru web; potrivită pentru scene interactive și vizualizare 3D. Nu oferă singură întregul workflow al unui game engine. | Investighezi un loader, un material, rendering sau un exemplu care nu este suficient explicat în docs. |
| **Babylon.js** — [repository](https://github.com/BabylonJS/Babylon.js), [docs](https://doc.babylonjs.com/) | Game/rendering engine 3D JavaScript orientat spre web; potrivit pentru experiențe și jocuri 3D în browser. | Ai nevoie de implementarea unui subsistem concret, precum scene, rendering sau import de assets. Integrarea nativă se evaluează separat de engine-ul web. |
| **Flame** — [repository](https://github.com/flame-engine/flame), [docs](https://docs.flame-engine.org/latest/) | Game engine construit peste Flutter, pentru jocuri în ecosistemul Dart pe mobile, desktop și web. | Investighezi game loop, components, coliziuni sau integrarea cu Flutter. Nu adăuga automat și sursa Flutter dacă problema este numai în Flame. |
| **Tauri** — [repository](https://github.com/tauri-apps/tauri), [docs](https://tauri.app/start/) | Framework pentru aplicații desktop și mobile cu frontend web, folosind renderer-ul web al sistemului și logică nativă; nu este game engine. | Investighezi comunicarea frontend/native, permissions, plugins sau un comportament specific platformei. |
| **Electron** — [repository](https://github.com/electron/electron), [docs](https://www.electronjs.org/docs/latest/) | Framework pentru aplicații **desktop** Windows/macOS/Linux cu Chromium și Node.js. Potrivit pentru utilitare și aplicații desktop cu UI web. | Investighezi un bug în runtime, IPC sau ferestre native. Nu îl selecta pentru o țintă Android/iOS. |

## Observații de selecție

- Pentru o aplicație mobilă uzuală, alege o direcție: React Native + Expo, Flutter sau un frontend web + Capacitor. Acestea sunt alternative de arhitectură, nu o listă obligatorie de repository-uri. Recomandare bazată pe platformele și rolurile descrise în sursele din tabel.
- Pentru primul joc 2D, Phaser este o opțiune pentru browser, Godot pentru workflow cu editor, iar Flame pentru un proiect Flutter. PixiJS și Three.js cer să construiești mai mult din infrastructura jocului. Aceasta este o recomandare de selecție, nu o comparație de performanță.
- Nu transforma suportul pentru browser mobil în promisiunea unei aplicații native. Testează platforma exactă, input-ul, grafica și packaging-ul proiectului ales.
- Instalarea unei dependențe și clonarea repository-ului ei sunt două acțiuni diferite. Pornește cu docs, exemplele relevante și sursele deja instalate. Adaugă un checkout când există o întrebare concretă, la tag/commit compatibil cu versiunea proiectului; nu clona întreg catalogul.
- React Native: URL-ul vechi `facebook/react-native` a redirecționat către `react/react-native` la verificare. Phaser: homepage și indexul docs nu au putut fi citite prin instrumentul web, dar pagina oficială „What is Phaser?” și repository-ul au fost citite. Babylon.js: indexul docs a răspuns fără text extractibil; URL-ul este confirmat de homepage și repository, folosite pentru descriere.
- Nu au fost instalate pachete, clonate repository-uri sau testate build-uri. Linkurile și rolurile sunt verificate documentar; selecția finală depinde de sarcina concretă.
